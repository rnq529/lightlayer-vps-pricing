## 国内访问：机房和线路怎么挑

三个变量决定体验：机房位置、线路档次、你所在的省市与运营商。

机房位置是物理条件。洛杉矶是美西，比纽约、芝加哥近几十毫秒；香港更近，但香港机房带宽通常更贵、配置起点更高。做参照的话，普通 BGP 线路的洛杉矶机房，第三方实测国内平均延迟在 190ms 上下，晚高峰可能有抖动，优化线路一般能压得更低。这个数字不是 LightLayer 的实测，只是给你一个判断基准。

线路档次是可控变量。CN2 是中国电信的承载网，CN2 GIA 是其中优先级最高的产品，价格也最贵；CU2 对应联通，CMIN2 对应移动国际。Premium 档把三网都做了优化，比只优化单家运营商的方案均衡。

最靠谱的做法是自己测。LightLayer 公布了各机房的测试地址，洛杉矶 Premium 是 `128.241.250.254`，香港 Premium 是 `156.245.234.254`，下单前 ping 一下、跑个路由追踪，五分钟的测试比看十篇测评有用。不同省份、不同宽带运营商的 result 差别很大，别人的数据只能当参考。
